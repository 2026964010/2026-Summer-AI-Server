# 이미지 생성 시 도구 호출 안정성 소규모 테스트

## 1. 테스트 목적

이미지 생성 요청 시 이미지 생성 도구가 안정적으로 호출되는지 확인하기 위함.


## 2. 테스트 방법

외부 LLM에게 각기 다른 이미지생성 프롬프트를 받고, 각각 새 채팅창에 작성한 후 정상적으로 이미지 도구를 호출하는지 확인, 그리고 정상적인 이미지를 생성하는지 확인하였다.


## 3. 테스트 환경
- 컴퓨터
  - CPU: Intel i5-13500
  - GPU: RTX 5070
  - RAM: DDR4 32GB
  - OS: Windows 11
- AI 모델
  - LLM: gemma4:12b (Thinking-medium)
  - ImageGenerationModel: juggernautXL_ragnarok.safetensors
- ComfyUI
  - 40-Step (20+20)
  - 1024*1024


## 4. 테스트 결과

총 10회 테스트를 수행하였다.

- 정상적인 도구 호출: 10회
- 도구 호출 실패: 0회
- 이미지 정상 생성: 10회
